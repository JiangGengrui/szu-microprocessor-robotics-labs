# 架构与设计

## 1. 目标与非目标

**目标**：在单颗 Cortex-M4F 上，用裸机代码完成三类此前需要 Linux + OpenCV 的工作——多传感器 UI、实时视频预览、模板/子空间人脸匹配，并保持毫秒级响应与可预测的时序。

**非目标**：多任务抢占、动态内存分配、通用驱动框架。四个应用各自独立编译，宁可复制少量代码，也不为"复用"引入跨应用的构建依赖。

## 2. 分层

```
apps/<app>/firmware/
├── Core/Src/main.c          应用编排：初始化顺序、主循环、状态机
├── Core/Src/<外设>.c        驱动层：GPIO / I2C / SPI / ADC / TIM / LTDC / DCMI / DMA2D
├── Core/Src/<业务>.c        业务层：灯效、任务、UI、算法
├── Core/Inc/<同名>.h        模块接口（模块之间只通过头文件交互）
└── Drivers/                 ST HAL + CMSIS（原样引用，不修改）
```

模块之间不共享全局状态，只调用对方头文件暴露的函数。`main.c` 是唯一的编排者。

## 3. 调度模型

全部应用采用 **单线程 + 时间片轮询**。没有中断里执行业务逻辑的代码，中断只做三件事：置标志、搬数据、清标志。

```c
uint32_t t_key = 0, t_effect = 0, t_heartbeat = 0;
while (1) {
    if (HAL_GetTick() - t_key >= 10) {          /* 10 ms：按键扫描 */
        t_key = HAL_GetTick();
        uint8_t ev = KEY_Scan();                 /* 边沿检测，长按只出一次 */
        if (ev) { BEEP_Beep(80); EFFECT_Set(ev); }
    }
    if (HAL_GetTick() - t_effect >= 150) {       /* 150 ms：动画推进 */
        t_effect = HAL_GetTick();
        EFFECT_Step();
    }
    BEEP_Task();                                 /* 到时自动关闭，非阻塞 */
    if (HAL_GetTick() - t_heartbeat >= 500) {    /* 500 ms：心跳灯 */
        t_heartbeat = HAL_GetTick();
        HAL_GPIO_TogglePin(LED0_PORT, LED0_PIN);
    }
}
```

时间片预算（`face-id` 为最重的一个）：

| 任务 | 周期 | 预算 | 说明 |
|------|------|------|------|
| 摄像头采集 | 每行 36 μs | DMA + DMA2D 硬件完成 | CPU 不参与搬运 |
| 按键 / 触摸逻辑 | 10–20 ms | < 50 μs | 边沿检测 |
| UI 局部刷新 | 200 ms | ~2 ms | 只重绘数值区 |
| 识别（一次） | 按键触发 | 0.3–4.2 ms | 见 §7 |
| 心跳 / 状态灯 | 500 ms | < 10 μs | — |

## 4. 内存地图

F429 片内 SRAM 仅 192 KiB，一帧 1024×600 RGB565 就要 1.17 MiB，因此外设与算法的工作区全部显式落在固定地址：

| 区域 | 地址 | 大小 | 用途 |
|------|------|------|------|
| 片内 Flash | 0x08000000 | ~80 KiB | 固件 text/rodata（含中文字库） |
| 片内 SRAM | 0x20000000 | ~62 KiB | data/bss + 8 KiB 栈 + 512 B 堆 |
| LCD 主帧缓冲 | 0xC0000000 | 1.17 MiB | 1024×600×2 B，UI 与视频共用 |
| 摄像头后缓冲 ×3 | 0xC0300000 / 0xC0440000 / 0xC0580000 | 各 1.25 MiB | 三缓冲，VBR 换页 |
| 算法工作区 | 0xC0700000 | 512 KiB | 特征脸、临时矩阵 |
| 特征脸模型 | 0xC0730000 | 108 KiB | 12 × 2304 × 4 B |
| NOR 图库 | 板载 NOR 独立扇区 | 200 KiB | 25 槽 × 8 KiB |

所有地址集中在 `Core/Inc/face_cfg.h`，改一处即可整体迁移。**指针运算的单位必须写清楚**：RGB565 强转 `uint16_t*` 后地址要乘 2，这个疏忽曾导致"只错一次"的 UI 错位（见 [apps/face-id](../apps/face-id/) 的已知问题）。

## 5. 显示管线

```
LTDC 扫描 SDRAM 中的帧缓冲 → RGB 并口 → 7 寸屏
        ▲
        │ 垂直消隐时换页（VBR）
   三块后缓冲
```

- 像素时钟：PLLSAI，`PLLSAIN=360, R=2, D=4` → 45 MHz，满足 1024×600 刷新带宽。
- 单图层（Layer1）指向当前帧缓冲；UI 与视频画面靠**写入区域互不重叠**分工，而不是靠图层叠加——双图层方案在本板上实测整屏无显示，已放弃。
- 换页只发生在两帧之间的消隐期，因此任意一帧都是完整画面，无撕裂。
- UI 更新采用局部重绘：只擦数值区的背景再写字符，避免整屏清屏造成闪烁。

## 6. 采集管线

```
OV5640 ──DVP 8 bit──> DCMI ──DMA2_Stream1──> 行缓冲 A/B ──DMA2D──> 后缓冲
                                                                    │
                                                              帧中断：请求 VBR 换页
```

F4 的 DMA 传输计数是 16 位（≤65535），整帧 1.2 MB 无法一次搬完，因此：

1. DMA 每次搬**一整行**（1024 px = 512 个 32 位字），双行缓冲轮转；
2. 行传输完成中断里用 **DMA2D** 把该行写进后缓冲（约 36 μs/行，CPU `memcpy` 无法满足）；
3. 一帧结束的 DCMI 帧中断里清标志、重新使能帧中断、请求 LTDC 换页。

## 7. 视觉流水线

```
取景框 480×480 ──10×10 块平均──> 48×48 RGB565 ──转灰度──> 2304 B
                                                            │
        ┌──────────────┬───────────────┬───────────────────┘
     MSE 2304 维   LBP 4×4×59=944   COL 3×16=48   PCA k=12
        └──────────────┴───────┬───────┴───────────────────┘
                        独立阈值 + 开放集判定
```

- 四种匹配器共用同一张 48×48 灰度图，输入完全一致，结果才可横向比较。
- 距离：MSE 用均方误差，LBP/颜色直方图用卡方，PCA 用低维欧氏距离。
- PCA 不分解 2304×2304 协方差矩阵，而是对 25×25 的样本 Gram 矩阵做特征分解，再用 `A·V` 构造特征脸；`k` 受 `N-1` 与特征值截断双重限制。
- 阈值在**验证集**上标定：两类分数分离时按 `min/max` 是否小于 3 选择算术中点或几何平均；重叠时取等错误率点。测试集只用一次。

完整的分数分布、误判机理与量化结论见 [apps/face-id](../apps/face-id/)。

## 8. 存储格式

人脸库每条记录 = 16 B 头 + 4608 B 图像：

| 偏移 | 字段 | 说明 |
|------|------|------|
| 0 | magic | 槽位有效标志 |
| 4 | version | 格式版本，升级时整体作废 |
| 5 | person_id | 1–5 |
| 6 | width/height | 48×48 |
| 8 | crc16 | 覆盖图像数据 |
| 16 | pixels | 2304 × RGB565 |

写入前核对 NOR 器件 ID 与数据区范围（不得覆盖程序与资源），写入后读回校验；启动时逐槽校验 magic + CRC，坏槽跳过而不整体失败。NOR 不可用时降级为"仅内存"，界面明示。

## 9. 定时器与中断资源

| 资源 | 用途 | 备注 |
|------|------|------|
| TIM6 | 1 ms 基准 | 中断只置标志 |
| TIM3 CH1/CH2 | 红/绿 PWM，1 kHz | 与捕获任务分时复用 |
| TIM4 CH1 | 蓝 PWM / 输入捕获 | PWM Input 模式测频率与占空比 |
| TIM1 CH1 + BKIN | N 次脉冲 + 硬件急停 | RCR + OPM；BKIN 清零 MOE |
| DMA2_Stream1 | DCMI 行搬运 | 双缓冲 |
| DMA2D | 行搬运、取景框填白 | 硬件加速 |
| SysTick | HAL 时基 | 1 ms |

## 10. 错误处理

- **外设初始化失败**（摄像头无应答、NOR ID 错误、传感器校验失败）必须变成**可见状态**，而不是静默重试：屏幕提示 + 红灯常亮，绝不显示过期数据。
- **故障安全**：急停走硬件通路（BKIN → MOE），软件只负责记录与人工确认恢复。
- **降级可用**：图库存储缺失时降级为内存模式并明示，功能仍可用，只是掉电丢失。
